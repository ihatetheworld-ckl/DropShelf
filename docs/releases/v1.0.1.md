## DropShelf v1.0.1 — 文件安全与稳定性更新

本版本修复了 v1.0.0 中可能覆盖同名目标文件、ZIP 遗漏同名内容及过早清理临时文件的问题，建议更新。

### 修复

- 移动不再先删除同名目标。同路径安全跳过；默认保留已有文件，也可重命名保留两份。
- 跨磁盘与应用生成的临时文件采用安全复制，保留源文件，并准确区分移动、复制、跳过和失败。
- ZIP 使用独立任务目录与输出路径，同名项目全部保留；失败保留原项目，完成时保留未选中和期间新增的内容。
- 临时资源使用共享所有权；已交给外部使用的文件持续保留，替代固定 30 秒删除；启动时安全清理应用拥有的孤立资源。
- 修正批量折叠判断、重复关闭、异步回调、空白架子超时行为及任务期间退出保护。
- 图片编码和文件操作在后台执行；快捷键注册失败可在偏好设置中查看。

### 安装包与文档

提供 Universal 2 的 DMG、ZIP、`SHA256SUMS.txt` 与 `release-manifest.json`。应用版本 1.0.1，构建号 2，最低部署目标 macOS 13.0。

重写 README，说明安装、交互、文件安全、缓存保留与已知限制。新增 CI 回归和安装包校验；打包在独立临时目录完成，保留旧发行输出。

### 验证范围

本地 34 项回归测试包含真实 APFS 跨卷复制、ZIP 解包内容、缓存生命周期、异步状态和 AppKit/Quick Look。发行校验检查 ZIP 与 DMG 中的内容、签名、版本、架构、最低部署目标及 SHA-256。

跨应用拖放、晃动/Option/菜单栏唤起、物理全局快捷键、取消拖拽、全屏和多屏仍需手动验收；Intel 和 macOS 13 尚无真机验收结论。不能将构建或 CI 通过视为这些体验已验证。

### 使用前须知

- 升级前处理旧架子中的内容并退出旧版本；架子列表不跨重启恢复。
- 已导出的临时文件持续保留，确认外部引用不再使用后可从偏好设置打开目录手动清理。
- 外部移动或改名不会自动更新路径引用；长时间文件任务暂无取消按钮。
- 发行包为 ad-hoc 本地签名，未经过 Apple 公证。请核对来源和 SHA-256 后按 macOS 系统提示处理首次打开。
