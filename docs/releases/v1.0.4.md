## DropShelf v1.0.4 — 通用双次 240ms 触觉反馈

本版本将已试用确认的通用双次触觉方案接入架子唤起：请求两次短反馈，间隔约 240 毫秒。目标是提供容易识别的提示节奏，不代表增加硬件振幅。

### 触觉提示与设置

- 新建或复用架子时，使用 Apple 公开 AppKit 接口请求 `.generic` / `.now` 通用反馈；第二次请求在主队列延迟执行，不阻塞交互。
- 默认启用触觉提示，未设置过样式时默认双次。升级保留已有触觉开关和已选择的单次/双次样式。
- 偏好设置可选择单次或双次，并点击“试震”比较。触觉与音效开关独立。
- 关闭后重新开启、切换样式、新的唤起或试震、对象释放都会使旧的延迟请求失效，避免过期提示。
- 对齐、压力变化等模式仅存在于独立开发实验工具中，架子唤起固定使用通用模式。实验工具源码随仓库提供，不是应用运行依赖。

### 验证范围

本机用户在试用通用双次 240 毫秒构建后确认“合适，保留当前方案”，已记录为手感与节奏的主观验收。Apple 的公开接口不提供振幅参数或执行成功回执，系统可能因输入设备、设置或手指未接触触控板而省略反馈；不将两次 API 请求等同于测得两次物理震动。

本地在 Apple Silicon、macOS 27.2 / Swift 6.4.2 上通过 71 项回归测试（0 失败、0 跳过），包含 8 项新增触觉调度与取消回归，以及原有拖出、文件安全、专用 APFS 跨卷、ZIP、缓存、架子状态和 Quick Look 测试。触觉自动测试使用注入请求与调度器；另检查真实主队列异步调度。

Universal 构建检查 arm64、x86_64、macOS 13.0 部署目标及 ad-hoc 签名；发行包校验包括 SHA-256、版本、构建号、ZIP 与只读 DMG 内的应用内容一致性。Intel、macOS 13 真机、其他触控板、Finder 端到端拖放、物理三指完整链路、多屏及全屏场景仍需单独验收，详细步骤见仓库测试文档。

### 下载与升级

版本 **1.0.4 / build 5**，最低部署目标为 **macOS 13.0**。提供 Universal 2 DMG、ZIP、`SHA256SUMS.txt` 和包含源码提交的 `release-manifest.json`。

升级前处理当前架子内容并退出旧版本，再打开新版，避免多个实例抢占快捷键；架子列表不跨重启恢复。需要支持 Force Touch 的触控板，并保持手指接触才能感知触觉提示。

安装包采用 ad-hoc 本地签名，未经过 Apple 公证。请核对来源和校验和，按照 macOS 系统提示处理首次打开。
