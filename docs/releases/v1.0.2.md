## DropShelf v1.0.2 — 触觉反馈与三指误触发修复

本版本加入架子唤起时的触觉提示，并修复拖拽结束后的残留数据导致空白三指晃动也唤起架子的问题。

### 新增触觉反馈

- 新建或复用架子时，通过 Apple 公开的 `NSHapticFeedbackManager` 请求一次短触觉提示。
- 默认开启，可在偏好设置中关闭“唤起架子时提供触觉反馈”；与音效开关相互独立。
- 需要支持 Force Touch 的触控板。系统会根据当前输入设备、触觉设置及手指接触情况决定是否提供反馈。

### 修复误触发

- 不再把拖拽剪贴板中残留的数据类型当成正在拖拽内容的证据。
- 晃动和 Option 唤起要求当前按下手势之后出现新的、应用可接收的拖拽内容。
- 同时处理应用内外的按下、拖拽与抬起边界，过滤架子自身拖出，保留冷却时间；同一次拖拽最多唤起一次。
- 同步更新 README、更新记录和手动验收步骤。

### 安装与验证

版本 **1.0.2 / build 3**，最低部署目标为 **macOS 13.0**。提供 Universal 2（arm64 + x86_64）DMG、ZIP、`SHA256SUMS.txt` 与 `release-manifest.json`。

本地 52 项回归测试覆盖残留数据、拖拽会话、真实私有剪贴板代际、Option、触觉请求与开关，以及原有文件安全、真实 APFS 跨卷复制、ZIP、缓存、窗口和 Quick Look。打包校验核对版本、签名、架构、最低系统目标、ZIP/DMG 内容一致性及摘要。

已在本机启动修复试用版并确认运行路径及快捷键注册成功。**物理三指手势与实际震动手感尚待手动验收**；触觉测试检查请求链路，不代表已经测得硬件震动。Intel、macOS 13 真机、多屏和全屏等原有验收范围见仓库测试文档。

### 升级提示

先处理旧架子的内容并退出旧版本，再打开新版本，避免多个实例抢占快捷键。应用若在拖拽中途启动，请重新开始拖拽。架子列表不跨重启恢复。

安装包采用 ad-hoc 本地签名，未经过 Apple 公证。请核对来源和校验和，按 macOS 系统提示处理首次打开。
