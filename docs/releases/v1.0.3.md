## DropShelf v1.0.3 — 拖出复制与移动行为修复

本版本修正从架子拖到 Finder 时的操作声明：原始文件和文件夹允许原生复制与移动，不再提供链接或自定义操作，避免普通拖出被协商为替身。拖出交互参考 [Dropover 官方说明](https://dropoverapp.com/tips)。

### 拖出行为

- 原始文件或文件夹交由 Finder 按同盘默认移动、跨盘默认复制处理；Option 请求复制，Command 请求移动。
- 增加“拖出时始终复制，保留原始文件”设置。开启后只提供复制操作，并忽略复制/移动修饰键。
- 应用生成的图片、文本、链接、ZIP，以及含它们的混合批次始终复制，保护其他架子和剪贴板持有的临时文件。
- 不提供创建替身的拖出操作；默认模式下 Option+Command 的替身组合不受支持。其他接收应用如何导入文件由该应用决定。

### 文件安全与架子状态

- 拖拽结束回调只更新架子，不自行删除源文件。Finder 负责实际文件操作、进度、同名冲突和取消。
- 取消和不支持的操作保留项目；重复完成回调只处理一次；拖拽期间新增的项目和未选中项目保留。
- 目标报告移动时，仅移除已离开原路径的引用，保留仍在原位置的项目供恢复；不会把断开目标的符号链接误判为已移走。即使关闭自动移除，失效的源路径也会移除。
- AppKit 不提供逐项完成结果，目标也可能异步处理。异步移动可能留下旧路径引用，需要手动移除；复制被接收后的后续失败，可能需要从原目录重新导入。需要逐项报告时，可使用架子菜单的“移动到指定文件夹”。

### 安装与验证

版本 **1.0.3 / build 4**，最低部署目标 **macOS 13.0**。提供 Universal 2（arm64 + x86_64）DMG、ZIP、`SHA256SUMS.txt` 与 `release-manifest.json`。

本地在 Apple Silicon、macOS 27.2 / Swift 6.4.2 上通过 63 项回归测试（0 失败、0 跳过），含专用 APFS 跨卷测试；新增 11 项拖出回归，检查真实 AppKit 源回调、URL 数据、设置快照、取消、重复结束、临时内容共享及部分移动保留。打包校验核对版本、签名、架构、macOS 13.0 部署目标、ZIP/DMG 内容一致性及摘要。

已正常退出旧版并启动本次修复试用版，核对运行路径。**Finder 实际拖放、Option/Command 效果及跨卷拖动仍待手动验收**，测试中的源回调不等同于 Finder 端到端实测。Intel、macOS 13 真机、物理三指手势与触觉、多屏和全屏场景也未完成实机验收。详细步骤见仓库测试文档。

### 升级提示

本版调整了 v1.0.2 的拖出策略。若希望始终保留原件，请在偏好设置开启“拖出时始终复制，保留原始文件”。升级前处理旧架子中的内容并退出旧版本，避免多个实例抢占快捷键；架子列表不跨重启恢复。

安装包采用 ad-hoc 本地签名，未经过 Apple 公证。请核对来源与校验和，按照 macOS 系统提示处理首次打开。
